For this activity, I chose the free Astra theme. It provides a clean and modern look that is highly customizable without the need to write custom code. Astra changes the way your site looks through its page builder and extensive customization options. For the pluging I chose the Limit Login Attempts plugin. Securing the login for the website from brute force attepts is extremely important. This pluging prevents that by limiting the number of login attempts allowed from a single IP address within a specified time period. If too many attempts are wrong the site will lock out the user.
